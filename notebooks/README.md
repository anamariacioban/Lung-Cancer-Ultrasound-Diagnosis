# Notebooks

This directory contains the Jupyter Notebooks used in the development of the project.

The notebooks cover the following stages of the processing pipeline:

- image preprocessing and noise reduction
- ultrasound region of interest (ROI) extraction
- semi-automatic lesion segmentation
- automatic lesion segmentation
- feature extraction
- model training and evaluation (Logistic Regression)

Each notebook corresponds to a specific stage of the system pipeline described in the main README file.
Note: Some inline comments inside the notebooks are written in Romanian, as the project was originally developed in Romanian.
