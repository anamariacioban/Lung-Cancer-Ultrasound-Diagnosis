# Computer-Aided Lung Cancer Diagnosis Using Transthoracic Ultrasound Images

This repository contains an academic project focused on the development of a computer-aided system for lung cancer diagnosis based on transthoracic ultrasound (TUS) image analysis.

The project explores image processing and machine learning techniques applied to lung ultrasound images in order to support the diagnostic process by automatically analyzing and classifying pulmonary lesions.

---

## Project Overview

Lung cancer is one of the leading causes of mortality worldwide. Early and accurate diagnosis is essential for improving patient outcomes. Transthoracic ultrasound imaging represents a non-invasive and low-cost imaging technique for lung lesion evaluation, but its interpretation is often subjective and highly dependent on the examiner’s experience.

This project aims to reduce subjectivity by developing an automated analysis pipeline capable of extracting relevant information from lung ultrasound images and providing a diagnostic classification.

---

## Methodology

The implemented system follows a sequential processing pipeline that includes:

- Image preprocessing for noise reduction and contrast enhancement
- Automatic extraction of the ultrasound region of interest (ROI)
- Lung lesion segmentation using image processing techniques
- Feature extraction based on lesion shape and intensity characteristics
- Classification of lesions into predefined categories
